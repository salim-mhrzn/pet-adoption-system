# 🐾 Pet Adoption System

A full-stack web application built using Django to help users browse, search, and adopt pets easily.

---

## 🚀 Features
- User registration and login system
- Browse and search pets by category
- Pet filtering functionality
- Adoption request system
- Admin dashboard to manage pets and users
- Priority-based ranking system for pets

---

## 🛠️ Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite


## ⚙️ Installation & Setup

```bash
# Clone repository
git clone https://github.com/salim-mhrzn/pet-adoption-system.git

# Move into project
cd pet-adoption-system

# Create virtual environment
python -m venv venv

# Activate virtual environment
venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt

# Run server
python manage.py runserver
